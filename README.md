# kuro-gif

Gifski wrapper for Kurogram (GIF encoding of stickers/media).

This is a snapshot copy of [Nekogram/gifski](https://github.com/Nekogram/gifski) (commit `3eeb892`, "bump version"),
imported without forking so Kurogram controls its own copy. The upstream license terms apply (see the license files). The Java package is `tw.kurocore.kurogram.gifski` (upstream: `app.nekogram.gifski`); the JNI symbols were renamed to match.

Build the AAR with the "Build AAR" workflow; it is pushed to the `aar` branch.
