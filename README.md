# kuro-gif

Gifski wrapper for Kurogram (GIF encoding of stickers/media).

This is a snapshot copy of [Nekogram/gifski](https://github.com/Nekogram/gifski) (commit `3eeb892`, "bump version"),
imported without forking so Kurogram controls its own copy. The upstream license terms apply; see the license files
in this repository and in `gifski/` for details. Kurogram currently still uses the published artifact
`app.nekogram.gifski:gifski`; switching to this module is a separate step.
